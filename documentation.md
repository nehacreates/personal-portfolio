4. Installation Guide

Follow these simple steps to get started:

Download the template ZIP file.
Extract the ZIP file to your computer.
Open the extracted folder.
Open the folder in Visual Studio Code or any code editor.
Locate the index.html file.
Open index.html in your preferred web browser.

Your website is now ready to preview!

You can also upload the complete folder to your web hosting account to publish your website online.

5. How to Customize
A. Change Website Name

Open index.html and find the brand name:

HTML
ALEX RIVERA


Replace it with your own name or brand.

Also update the page title:

HTML
<title>Alex Rivera | Full-Stack Developer</title>

B. Change Hero Section Content

Find the hero section inside index.html.

Update the heading and description according to your profession and personal branding.

C. Change Images

Open the images folder.

Replace the existing images with your own images while keeping the same filenames.

Available image files:

girly.png – Hero illustration
p-.png – About section illustration
p1.png – Process section illustration
p2.png – Contact section illustration
project-store.png – E-commerce project preview
project-dashboard.png – Dashboard project preview
project-cafe.png – Business website preview
project-fitness.png – Fitness application preview

Important: Keep the filenames and image paths unchanged unless you also update their references in HTML.

D. Change Colors and Styling

Open:

text
style.css


You can customize:

Background colors
Text colors

Font sizes

E. Update Projects

Find the Case Studies section in index.html.

You can change:

Project names
Project descriptions
Project categories
Technologies
Project preview images

Duplicate an existing project card to add more projects.

F. Update Services

Find the Services section.

Edit the service titles, descriptions and technology lists according to your requirements.

G. Update About Section

Customize the following:

Personal introduction
Professional experience
Skills
Technologies
Personal achievements
H. Update Testimonials

Find the Testimonials section.

Replace the demo testimonial content with genuine customer feedback.

I. Update Contact Information

Find the contact section and replace:

HTML
mailto:hello@alexrivera.dev


With your own email address.

Also update the email address in the footer.

J. Update Social Media Links

Find the footer social links.

Replace the existing GitHub, LinkedIn and Dribbble URLs with your own profile links.
